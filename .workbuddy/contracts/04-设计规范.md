# miniworld · 04 设计规范

> 本文件是视觉语言、组件、响应式、交互与可访问性的**唯一权威**（内部实现规范）。
> 依据：README §一（设计语言）/ §四（页面骨架、卡片结构）/ §六（视觉）/ §七（交互）+ 05 骨架继承清单（css/main.js 改造）。
> **双轨说明**：README 讲的是"给用户/世人看的纯手工流教程"（手写 HTML 也能做出同样效果）；本契约讲的是"内部实现规范"（build 生成 + CSS/JS 落地）。两者视觉与交互结论必须一致，改一处须回查另一处（06 文档治理 §3 校准）。

## 一、设计语言（视觉）

- **风格定位**：正红主色 + 白色大底色 + 金色点缀，清爽克制、不堆砌。
- **配色（亮色）**：红系主色 + 金系点缀 + 白底（具体色值以 `docs/assets/css/style.css` 变量为准）。
- **暗色模式**：复用同一套配色延伸到暗色，**禁止偏蓝、偏紫、科技冷淡、廉价渐变**。实测值：暖炭 `#1E1B1F` / 暖炭灰 `#2A252A` / 香槟金 `#D9B978` / 象牙白 `#ECE6DF`（与 `[data-theme="dark"]` 一致）。
- **暗色切换**：用户手动切换（**不跟随系统偏好**），状态存 `localStorage('zx_theme')`，加载前同步防闪烁（FOUC）。
- **字体基准**：`html` 16px + `text-size-adjust:100%` + 表单控件 `font-family:inherit`，不得删除（跨浏览器一致）。
- **铁律**：任何新 UI 必须服从这套语言，不擅自引入新主色或新视觉调性。变更先呈报（§六）。

**视觉细节禁区（避坑清单）**：
- 分类按钮**不放数量/计数徽章**（与结果计数行重复）。
- 暗色切换按钮**不占用吸顶区**，固定放页脚工具簇。
- 卡片文本**允许框选/复制**（已移除 `user-select:none`），链接点击与文本选择互不冲突。
- 空结果状态**不做"清除所有筛选"按钮**，只显示提示文案。

## 二、组件规范

### 2.1 卡片三类型（D-13）

| 类型 | 布局 | 封面比例 | 用途 |
|---|---|---|---|
| type 1 | 4 行 3 列：图片（跨两行）/ 名称+收藏 / 描述（跨两列）/ 标签行 / 链接行 | 方形 logo | 主形式，密集紧凑 |
| type 2 | 5 行 2 列：封面（跨两列）/ 名称+收藏 / 描述 / 标签行 / 链接行 | 横向 1.618:1 | 优质横版图 / 广告展示位 |
| type 3 | 5 行 2 列：同 type 2 | 纵向 1:1.618 | 图书/影视封面、人物照（百科词条式） |

**通用约束（三类一致）**：
- 均有收藏按钮（内联 SVG 星形，描边金→收藏后填充金），固定在名称行右端。
- 名称/描述/标签/链接**必有**（无链接也空占位，不加提示文字），只占一行，超出截断/横向滚动。
- 卡片内所有内容允许框选/复制。
- 标签行第 1 个标签固定为分类名，可点击筛选。
- 卡片按站序 `row_seq` 源序排列，**type 不参与排序**；相邻 type 变化处插入 `.grid-break` 强制换行，不同类型绝不同行。
- 媒体区无图时用**首字占位**兜底，不破版；图片统一 WebP 且保留透明通道（RGBA），否则透明 logo 被填黑。

### 2.2 其他组件

| 组件 | 规范 |
|---|---|
| 分类行/标签行/引擎行 | `.track` 通用滑道：横向溢出 + 悬停滚轮左右滚动 + 移动端触摸滑动 |
| sticky 区 | 分类行 / 站内搜索 / 结果计数 / 筛选标签包在 `.sticky-top` 内整体吸顶 |
| 滚动按钮 | `.scroll-btn` 4 状态（up/top/down/bottom），`position:fixed` 右下角，按位置 `.is-active` 只亮 1 个；**声明条显示时按钮上移避让（空间分离为主，z-index 双保险）** |
| 第三方声明条 | `.official-banner` 底部固定可关闭；与滚动按钮空间分离避让（z-index 双保险）。触发与 30 天机制见 08 合规规范 §四（唯一权威） |
| 页脚 | 版权 + 完整 URL 导航 + 备案号占位（仅国内域名有 ICP 时显示）+ 工具簇（sun/moon） |
| 搜索框（搜索工具页） | `hero__search` 主引擎 + 搜索框 + 引擎滑道，21 个 `data-engine`，回车跳转 |

## 三、响应式与布局

- **Grid 列数**：桌面 4 卡 / 平板 3 卡 / 移动 2 卡。
- **吸顶**：sticky 区滚动时吸顶，声明条不侵入吸顶区。
- **滑道**：触摸滑动须可用（T6，见 §四）。
- **404 页**：自包含（内联样式 + 绝对域名 logo），可从任意深层路径触发。

## 四、交互规范（JS 行为）

| 交互 | 规范 |
|---|---|
| 三维度筛选 | 分类 + 关键词 + 本地收藏 AND 叠加；状态 URL 分享（`#cat=分类名`） |
| 本地收藏 | 星形 toggle，存 `localStorage('zx_favs')`；「本地收藏」只显示已收藏 |
| 结果计数 | 无筛选「共 N 张卡片」，筛选后「当前显示 X / N」，0 结果红色提醒 |
| 集合搜索 | 21 引擎，回车跳转对应结果页 |
| 滚动按钮 | `safeScrollTo` 三段降级：smooth → 老内核两参数 → 120ms 未动再降级；任何"先锁后滚"必须保证失败也能解锁 |
| 暗色切换 | 页脚 `theme-toggle`，存 `localStorage('zx_theme')`；FOUC 防闪烁；**禁止 `scroll-behavior:smooth`**（与 JS 滚动冲突致按钮失效） |
| 声明条 | 触发/30天机制/时间戳/未关续显规则见 **08 合规规范 §四**（唯一权威）；本契约只管其视觉与避让布局 |
| 外链属性 | 同主域 `_self` > 同族站新窗隔离 opener > 营销 `sponsored` > 评论 `ugc` > 政务官方（`noopener` + `referrerpolicy="origin"`）> 默认 `nofollow noopener noreferrer` |

## 五、可访问性与降级

- skip-link 生效；图片 alt 齐全；标题层级正确（H1 唯一）。
- **禁用 JS**：内容完整可读可点（纯静态 HTML 降级，SEO 基础）。
- 卡片文本可框选复制；键盘可达（焦点态清晰）。

## 六、变更纪律（可执行）

1. **先呈报后动手**：任何 HTML 结构改动必须先造物主呈报、拍板。
2. **新功能只新增元素，禁改结构**：优先在既有骨架上加模块，不动既有 DOM 层级。
3. **改 CSS/JS 必跑回归**：改 `main.js` → `node .build/qa-scroll-check.js`（退出码 0=过）；改 `#consent-bar` → `.build/qa-consent-check.js`；改 CSS → 核对版本戳注入（05 §六·补）。
4. **双轨回查**：改内部实现 → 回查 README 视觉/交互描述是否仍一致（06 文档治理 §3）。
5. **T6 真机**：触摸滑动类改动须小米浏览器 + 微信 + Chrome 三端实测（见 05 §五）。
