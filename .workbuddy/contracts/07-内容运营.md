# miniworld · 07 内容运营

> 本文件是日常运营（收录 / 审核 / 更新 / 死链 / 反馈 / 统计 / 台账）的**唯一权威**。
> 依据：01 产品定义（做/不做边界、D-04/D-05/D-17）+ 04 校验（L3 死链、L5 监控）+ 前期运营教训（见 `memory/2026-11-26.md` 第一部分快照）。
> 运营对象 = 仓库根 `xlsx/cards-pages/` 编辑源；内部台账放 `.workbuddy/memory/`（剥离小世界时不带走）。

## 一、角色边界（谁做什么）

| 角色 | 职责 | 不做 |
|---|---|---|
| 造物主 | 收录/纠错拍板、灰色判定、分类排布、row_seq 手排、上线决策、邮件/共享表反馈提取、统计自看 | 不碰 git 之外的自动化细节 |
| agent | 提醒周期任务、辅助核验、死链扫描、台账跟进、解读统计 | **不执行 git**（造物主收口）、不擅自拍板、不擅自改 xlsx 数据 |

**铁律**：任何收录/删除/改类目须造物主拍板；agent 只提醒与执行已拍板项。git 操作全停由造物主执行。

## 二、收录流程（可执行）

1. **渠道**：收录申请 = 在线共享表格（腾讯/金山/石墨等，填写人仅见自己内容），字段格式对齐 cards 可填子集（见 03 数据模型 §四）。**不做假提交页面**。
2. **核验**：造物主核验——公开权威稳定 / 是否灰色服务（§三）/ 分类归属 / 是否有官网。
3. **入库**：核验通过 → 复制粘贴入 `xlsx/cards-pages/*.xlsx`（零转换）→ merge → build。
4. **上线**：跑 06 校验 L1/L4 → 造物主拍板 → git 推送（造物主执行）。
5. **无链接卡**：机构存在但暂无官网 → 保留卡片、链接行留空占位、不加提示文字（D-04）。

## 三、内容审核规范

**永久屏蔽（按网站性质判定，非按词）**：以代办/代开/加急/包过/贷款中介/协助贷款公司/下载器为核心服务的灰色网站不收录。银行/政务页面出现"贷款"等词**正常收录**（词≠业务模式）。

**收录标准**：公开、权威、稳定。只收录官方公开入口，不做内容托管、不做商业化导流。

**政务/官方专题**：中文名必带第三方属性词（导航/索引/入口），防假冒官方（见 08 合规规范 §二）。

**内容边界**：本站只做索引，不生成政务/民生资讯；只挂外部链接，内容永远在外部。

## 四、更新频率与批量纪律

- 收录/删除按造物主节奏，不设硬性日配额；**小批量、逐条拍板，每批 ≤10 条**。
- 改数据后必记当日日志（含决策原因，DEC-007）。
- 边吸边删（D-17）：前期项目内容按"提取→提纯→决策→吸收→删除"逐步消耗，剩壳即退役时刻。

## 五、死链检查（L3，周期任务）

- **时机**：收录前后 + 每月全量；agent 为闹钟，到点提醒（造物主可回"本月跳过"）。
- **工具**：`.build/check_links.py`（数据源 cards xlsx → link_report），报告落 `.build/reports/`。
- **处置**：断链 → 造物主拍板修复/移除；结果记入反馈台账。
- 月度死链检查是 cycle-task，登记于周期任务清单。

## 六、反馈处理（闭环）

**台账**：`.workbuddy/memory/feedback-log.xlsx`（append-only）
| 列 | 说明 |
|---|---|
| 日期 | 反馈日期 |
| 来源平台 | 邮件 / 共享表 / 其他 |
| 反馈类型 | 建议 / 纠错 / 收录 / 其他（下拉） |
| 指向页面 | 首页 / 政务导航 / 搜索工具 / 其他 |
| 内容摘要 | 简述 |
| 处理状态 | 下拉：待处理 / 处理中 / 已闭环 / 豁免 |
| 处理结果 | 处置结论 |

**流程**：反馈 → 造物主提取入台账 → agent 跟进 → 修复/收录/解释 → 状态改"已闭环"；未闭环项下次会话提醒。

## 七、统计与观察（L5）

- **工具**：GA4 / 百度统计（按 `pages.unified.xlsx` 开关注入，见 03 数据模型 §二）。
- **分工**：统计后台由造物主自看；agent 提醒/解读数据；反馈由造物主提取。
- **域名迁移**：当前境外 GitHub Pages 保留 GA4/AdSense；未来迁境内时改 xlsx 关闭（D-16，见 01/05）。
- 不设全局 no-referrer，仅卡片图片单独压制（隐私见 08 合规规范 §六）。

## 八、运营台账清单（事实源）

| 台账 | 路径 | 用途 |
|---|---|---|
| 反馈台账 | `.workbuddy/memory/feedback-log.xlsx` | 反馈闭环（§六） |
| 上线检查记录 | `.workbuddy/memory/上线检查记录.xlsx` | L4 真机检查（检查项/类别/agent预检/造物主真机/结果下拉/备注，12 项） |
| 周期任务清单 | cycle-tasks.md | 月度死链等闹钟事项 |

> 造物主填写文件一律 xlsx（含下拉与彩色表头）；agent 读取如实。
