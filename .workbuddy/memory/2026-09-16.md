# 2026-09-16 工作日志

## zhengxie.com.cn → zhengxie.info 全域名 301 跳转（已生效验证）
- 需求：旧域名 zhengxie.com.cn（.cn 未备案）访问全部 301 跳到 zhengxie.info；页面无所谓，都到 info 即可。
- 最终方案（Cloudflare 边缘跳转，免备案/免费）：
  1. Cloudflare 接管 zhengxie.com.cn 的 NS（anahi/jack）；阿里云侧**改 DNS 服务器**（非加解析记录）。
  2. Cloudflare DNS 加两条**橙色代理**占位 A 记录：`@` 和 `www` → `192.0.2.1`（RFC5737 TEST-NET，不路由；因代理，请求被边缘拦截执行跳转，假 IP 永不被访问）。
  3. SSL/TLS 加密模式 = Full。
  4. 规则 → 重定向规则：所有传入请求 / 动态 / 表达式 `concat("https://zhengxie.info", http.request.uri.path)` / 301 / 保留查询字符串=开 / 部署。
- 验证（本日）：`curl -I https://zhengxie.com.cn/` → 301 + `Location: https://zhengxie.info/` + `Server: cloudflare` + `CF-RAY ...-BKK`，生效。
- 踩坑备忘：Cloudflare 重定向规则**必须**有橙色代理 DNS 记录才触发；纯跳转域名不加占位 A 记录会 `Could not resolve host`、规则不执行。
- 合规：.cn 须过实名认证（已确认通过）；保持 Cloudflare 全球节点（免备案），勿开中国大陆节点（需备案）。
