# miniworld · 08 合规规范

> 本文件是合规与切割（第三方属性 / 命名 / 内容 / 声明条 / 链接 / 隐私）的**唯一权威**。
> 依据：01 产品定义（切割第一优先、D-18、命名通则 DEC-008）+ 04 设计规范（外链属性、声明条 UI）+ 旧世界合规教训（见 `memory/2026-11-26.md` 第一部分快照）。
> **第一优先**：避免违规、避免被误认/假冒官方——所有合规判断以此为准绳。

## 一、切割第一优先（全站最高合规约束）

- 本站是**独立第三方导航站**，与任何官方机构无隶属关系、无官方授权；收录链接仅作索引聚合，不代表本站立场或担保。
- **不做**：冒充官方 / 使用官方标识 / 自称官方 / 名称与视觉指代官方机构。
- **整站级可信信号**（做-4）：非官方声明 + Organization 机器可读 JSON-LD + 链接露真域名；页面/卡片/链接级徽章暂不做。
- 名称和 slogan 永不改（正协导航 / "让每一次寻找，都不止于找到"）——既吃政协流量，又须靠声明条与命名切割守住第三方属性。

## 二、命名合规（DEC-008）

1. **凡涉及官方/政务内容的专题，中文名必须带第三方属性词**（导航 / 索引 / 入口）——裸"政务"会让用户误认官方政务平台；"导航"明示第三方，一劳永逸防合规风险。已定案：gov 中文名 = **政务导航**（N-05）。
2. **纯工具/文化类专题不受此限**（搜索工具 / 百家姓 / SNH48 等——不涉及官方，无误导风险）。
3. **命名标准**：用词准确，对用户、机器无理解障碍和歧义；废弃旧世界"差异化竞争避开热门关键词"思路（准确 > 避关键词）。禁关键字回避技巧。
4. 新专题立项时须过此关（流程见 02 信息架构 §六）。

## 三、内容合规

- **永久屏蔽**（按网站性质判定，非按词）：以代办/代开/加急/包过/贷款中介/协助贷款公司/下载器为核心服务的灰色网站不收录。银行/政务页面含"贷款"等词**正常收录**。
- **不生成政务/民生资讯**：只挂聚合索引，用户点击跳外部看内容；本站不写/不转/不承载政务民生内容，内容永远在外部。
- **收录标准**：公开、权威、稳定；只收录官方公开入口，不做内容托管、不做商业化导流。
- **广告合规**（D-15）：政务/机构专题零广告（`ad_slots` 留空）；非政务专题广告位带右上"广告"小字标识；404 页不放广告。广告容器左右零 margin/padding。

## 四、第三方声明条（D-18，可执行）

- **内容**：独立第三方声明，与 README 非官方声明一致（§一）。
- **触发**：首次访问显示；点「×」关闭 → `localStorage('zx_notice_closed')` 记时间戳 → **30 天内不再显示、超期重显**；未关闭离开不记录、下次继续显示。
- **UI**：底部固定可关闭；空间分离避让滚动按钮（z-index 双保险）；见 04 设计规范 §二。
- **回归**：改 `#consent-bar` 必跑 `.build/qa-consent-check.js`。
- **原因**：切割铁律落地（用户首次接触即知第三方属性）；旧世界 A1 曾实现同款但元素/JS 丢失只剩 CSS 残留，新世界做完整版。

## 五、链接合规

- **外链属性优先级**（04 §四，合规相关部分）：同主域 `_self` > 同族站新窗隔离 opener > 营销 `sponsored` > 评论 `ugc` > 政务官方公开来源（`noopener` + `referrerpolicy="origin"`，传递权重）> 默认 `nofollow noopener noreferrer`。
- **露真域名**：链接展示真实目标域名，不伪装、不缩短隐藏。
- **内链绝对化 + 资源相对化**（05 §三·补）：nav 内链完整 URL、静态资源相对路径。
- **断链**: 定期 L3 检查（07 §五），断链及时修复/移除。

## 六、数据与隐私

- **无后端**：不做假提交页面；反馈/收录走第三方共享表格或邮件（07 §二）。
- **本地存储**：收藏 `zx_favs`、主题 `zx_theme`、声明条 `zx_notice_closed` 均存浏览器 localStorage，不上传服务器。
- **统计**：GA4 / 百度统计按 xlsx 开关注入；隐私政策见 `pages/privacy/`；**不设全局 no-referrer，仅卡片图片单独压制**。
- **备案号**：仅国内域名有 ICP 备案时显示（页脚占位，未备案不渲染）。
- **坐标保护**：`docs/` 公开层零仓库坐标真值；本条是合规落地，**法则与扫描口径的唯一权威 = 宪法 §十**（含暴露分级与 grep 模式），此处不复述。
